Claude（Anthropic）をチャットツールとして「答えを聞く」用途に使うより、「自分の考えを整理する相手」として使う方が、自分には合っていると感じてきた。本業でAI活用の推進をしている立場から、企画・アイデア出しの場面でどう使っているかを書く。

## 「壁打ち相手」として使う、の意味

一般的なLLMの使い方は「質問→回答」の構造だが、企画を磨く用途では少し変えると効果的だった。

**自分が使っている構造**

1. 自分の仮説・アイデアをまず書く（箇条書きでいい）
2. 「この考えの弱い点を指摘してほしい」と依頼する
3. 指摘を踏まえて、自分の考えを書き直す
4. 繰り返す

ポイントは「答えを聞く」ではなく「自分の考えを先に出す」こと。LLMに答えを出させると、その答えに引っ張られて自分の思考が止まりやすい。

## 具体的なプロンプトパターン

**弱点を探させる**

```
以下は私が考えている企画案です。
この企画の弱い点、見落としている観点、実現が難しそうな部分を指摘してください。
企画案を肯定的に評価するのではなく、批判的な視点で見てください。

[企画案をここに書く]
```

**別の切り口を出させる**

```
この企画を、まったく逆のアプローチから考えると、どんな案が考えられますか？
私が考えた案と対比する形で3案ほど出してください。
```

**想定反論を作らせる**

```
この提案を会議で出した場合、よくありそうな反対意見や質問を5つ列挙してください。
それぞれに対して、どう答えると説得力があるかも添えてください。
```

## 長い会話セッションの管理

企画の壁打ちは会話が長くなりやすい。コンテキストウィンドウに注意しながら使うポイント：

- セッションの最初に「このセッションの目的」を明示する
- 途中で「ここまでの議論の要点をまとめてほしい」と整理を挟む
- 結論が出たら別ファイルに書き出し、次のセッションで参照する

## 「Claudeの答えを正解にしない」

壁打ち相手として使う上で一番気をつけていること：Claudeの指摘や提案を「正解」として受け取らない。あくまで「自分が見落としていた視点のヒント」として扱い、採否は自分で判断する。LLMは「それっぽい答え」を出すのが得意なので、自分の批判的思考を止めないための意識的な構えが必要だと感じている。
